# go-sfomuseum

Go package for working with SFO Museum related documents.

## Motivations

This pacakage bundles and supersedes the following packages:

* `sfomuseum/go-sfomuseum-architecture`
* `sfomuseum/go-sfomuseum-airfield`
* `sfomuseum/go-sfomuseum-curatorial`
* `sfomuseum/go-sfomuseum-edtf`
* `sfomuseum/go-sfomuseum-export`
* `sfomuseum/go-sfomuseum-feature`
* `sfomuseum/go-sfomuseum-geo`
* `sfomuseum/go-sfomuseum-instagram`
* `sfomuseum/go-sfomuseum-instagram-publish`
* `sfomuseum/go-sfomuseum-maps`
* `sfomuseum/go-sfomuseum-placetypes`
* `sfomuseum/go-sfomuseum-spatial`
* `sfomuseum/go-sfomuseum-twitter`
* `sfomuseum/go-sfomuseum-twitter-publish`
* `sfomuseum/go-sfomuseum-validate`
* `sfomuseum/go-sfomuseum-whosonfirst`
* `sfomuseum/go-sfomuseum-writer`
