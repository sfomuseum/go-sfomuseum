# go-sfomuseum

Still-experimental work to create a common (but not universal) `go-sfomuseum` library.

## Work in progress

Currently, this pacakage aims to bundle (and eventually supersede) the following packages:

* `sfomuseum/go-sfomuseum-architecture`
* `sfomuseum/go-sfomuseum-airfield`
* `sfomuseum/go-sfomuseum-curatorial`
